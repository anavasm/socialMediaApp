# 📱 Social Media App

A sleek social media mobile application built with **React Native CLI** and **TypeScript**. 

This repository is a **Pet Project** focused on practical learning, modernizing legacy course materials, and applying software engineering best practices for mobile UI development.

---

## 🚀 Features & Screens
- **Main Feed:** Dynamic posts layout with interaction counters (likes, comments, shares) and horizontal Stories section.
- **User Profile:** Metrics overview (followers, following, posts) and a content grid tab system (*Photos, Videos, Saved*).
- **Messages Inbox:** Chat list view with search filter, avatars, active status, and last message previews.
- **Interactive Chat UI:** Individual conversation screen with styled text bubbles and direct messaging controls.

---

## 🛠️ Tech Stack
- **Framework:** React Native CLI
- **Language:** TypeScript
- **State & Navigation:** React Navigation
- **Architecture:** Component-based modular structure

## 💻 Getting Started

### Prerequisites
Make sure you have completed the official [React Native Environment Setup](https://reactnative.dev/docs/set-up-your-environment) guide for Android or iOS.

### 1. Installation
Clone the repository and install dependencies:

```sh
git clone [https://github.com/anavasm/socialMediaApp.git](https://github.com/anavasm/socialMediaApp.git)
cd socialMediaApp
npm install
```

### 2. Start Metro Bundler
Start the JavaScript build tool:
```sh
npm start
```


### 3. Run the App
Open a new terminal window from the project root and run:

Android:
```sh
npm run android
```

iOS (macOS only):
```sh
# Install CocoaPods dependencies (first time or after updating native deps)
cd ios && bundle exec pod install && cd ..

# Run iOS Simulator
npm run ios
```
